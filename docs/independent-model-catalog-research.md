# Independent model catalog research — incomplete

The official OpenGateway data-plane endpoint https://apis.opengateway.ai/v1/models was fetched successfully without credentials. Its public website endpoint https://opengateway.ai/api/public/models returns the same catalog shape. The official API documentation https://opengateway.ai/docs/reference/guides/overview identifies the data-plane model endpoint. The snapshot contains 102 models, with factual fields id, status, modalities, endpoints and context_window. Public-API observation of the current Scrum defaults found 60 existing IDs; every ID is present in the official snapshot.

Do not blindly register all rows for OpenAI completions: the catalog includes retired, image-generation and responses-only entries. Existing user settings must remain authoritative. The official payload does not supply reasoning capability, maximum completion tokens or gateway pricing, so it is insufficient by itself to preserve all current metadata behavior. The public OpenRouter endpoint https://openrouter.ai/api/v1/models supplies model capabilities and output limits for 62 exact IDs, but its pricing is NOT authoritative for OpenGateway and must not be substituted. Non-exact IDs must not be guessed from similar names. OpenGateway /control-plane/models requires authentication (401); guessed management /api/v1/models and data-plane /openapi paths returned 404 in this run. No authentication change or credential disclosure occurred.

Raw research snapshots are private temporary files under /tmp/scrum-opengateway-*.json and /tmp/scrum-openrouter-public-models.json; no descriptions or protected source were copied into a distributable. The existing protected model asset remains wired until a complete, appropriately sourced replacement is validated. This research does not close the replacement or licensing gate.

## Official gateway pricing discovery

The public promo page references https://opengateway.ai/api/model-prices. A fresh unauthenticated request succeeded and returned 523 route records. Exact modelOwner/modelName matching yielded gateway prices for 100 of 102 catalog models; 67 have multiple provider routes. These are per-token amounts, with current effective discounts and conditional pricing axes; a single flat rate cannot represent every route, time window or team fee. The independent transformation retains routes and observation timestamps without importing OpenRouter prices. Two targeted regression tests passed, including route ambiguity, exact IDs, null unknowns, invalid negative prices and discount units. Pi AI 0.87.1 MIT metadata also provides exact manufacturer entries for some missing output limits, but several remain unavailable. The active protected catalog is still not replaced; full runtime and provenance gates remain open.
