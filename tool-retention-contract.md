# Native output retention and AST provisioning

Pinned reference: oh-my-openagent `59d23b5c1ddc2a02210ede4cb485f88996fd02bd`.

`tool-retention.mjs` keeps the original tool-output-truncator eligibility list and budgets, copied with source hashes into `vendor/omo/tool-retention-contract.mjs` and its provenance file. Webfetch/WebFetch receive 10,000 tokens; the native SDK name `web_fetch` maps to the same source operation; the other eligible tools receive 50,000. `experimental.truncate_all_tool_outputs=true` extends the 50,000 budget to other tools. `disabled_hooks:["tool-output-truncator"]` disables this source projection. Configuration is resolved for each accepted result and each PTC dispatch log, so edits take effect without restarting the host.

The native adapter calls the public `@deepseek-ai/dsh-spill-policy.apply` API through a filtered context. Its model token estimator prices the native content, including image descriptors when supported. The public token meter and model information reduce the cap to half the remaining context when both are available; unavailable usage retains the source fallback cap. Exhausted text context suppresses the preview after saving the full bytes. A recovery locator is still retained. Missing recovery storage keeps the original inline content and reports the failure.

DSH's deployment spill policy remains independently active. The source projection runs before its outer baseline and does not install or change a global deployment budget. Disabling the source hook therefore does not disable DSH retention. The acceptance explicitly configures a 5,000-token native baseline to prove this separation; the installed SDK's deployment default is owned by DSH and may differ. Top-level canonical tool values and values returned to a PTC program remain intact. Only model-facing content and persisted PTC dispatch display copies are projected. Full formatted source text remains recoverable from the spill store.

`ast-runtime.mjs` adapts the original asynchronous sg provision hook to the explicitly pinned `@ast-grep/cli` npm dependency. npm optional platform packages and that dependency's postinstall provision the executable before host startup. Every native AST tool validates availability/executable permission and uses that binary. Failure names the current platform/architecture and instructs the operator to install optional dependencies and rebuild with postinstall enabled. It never downloads a replacement or falls back to text grep.

Run `node scripts/test-live-acceptance.mjs retention` with `SCRUM_ACCEPTANCE_EVIDENCE` pointing to an external evidence directory. This executes the isolated source/native baseline matrix and the actual index-wired carrier, with no model calls. The controlled missing-binary native failure is exercised only in the isolated carrier; both carriers execute the installed platform CLI.
