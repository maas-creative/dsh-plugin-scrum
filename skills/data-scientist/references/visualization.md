# Figures that reflect the evidence

Choose a figure from the analytical question. Comparisons need common units and a meaningful baseline; time series need explicit time coverage; distributions need enough detail to show variation. A visual decoration is not evidence.

Create numerical plots directly from the verified data. Preserve the table or transformation used to create each plot. Label measures, units, categories, periods and uncertainty where relevant. Use readable text, accessible contrast and distinguishable marks; do not rely only on color. Explain exclusions and aggregation choices in accompanying prose.

Check axis ranges, scales, denominators, missing observations and sorting. Do not hide uncertainty or imply continuity across missing periods. Use consistent scales when comparing panels unless a clearly explained analytical reason requires otherwise. Inspect the exported artifact at its intended display size.

Separate data graphics from conceptual illustrations. Follow the user's instructions about illustration tools and document captions. Do not turn an illustrative diagram into a quantitative claim or add invented values to make a chart look complete.

Provide the requested formats and keep plots connected to source code and data. Confirm that exported files open correctly, are not clipped, and match the reported numbers. State limitations and avoid causal visual claims unsupported by the analysis design.
