# Platform selection

Pi and Senpi: `senpi`, with `.pi/agent` and `.senpi/agent` roots.
OMP: `oh-my-pi`, with `.omp/agent`.
Gajae: `gajae-code`, with `.gjc/agent`.

The bundled finder also registers codex, claude, aside, opencode, openclaw, droid, amp, qwen, kimi, gemini, codebuff, roo-code, kilo-code, cline, kilo-cli, hermes, goose, crush, cursor-cli, zed, aider, kodu, and kiro. Each reader has its own store shape; do not relabel a foreign JSON file merely to make it appear in results. `--root` adds a specific transcript/store root; it does not change the platform's expected format.

For missing records, check the original application's history location and archived logs. Read-only SQLite access and file parsing must leave those originals intact. Prefer narrow query, date, project and platform filters before broad searches.
