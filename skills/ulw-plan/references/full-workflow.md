# Planning through delivery

1. Establish the requested output, completion condition and preserved records.
2. Inspect current runtime paths, configuration and tests; identify actual gaps.
3. Create tasks with tangible outputs, dependencies and acceptance evidence. Include final verification and release work within the authorized scope.
4. Implement using the configured model and delegation policy. Track failed and waiting work without treating them as completed.
5. Verify artifacts against the task acceptance condition before updating progress. Collect delegated results when delegation is authorized; their termination alone is not verification.
6. Run the connected product flow and appropriate regressions. Repair failures and repeat affected checks.
7. Reconcile every requested completion condition with evidence. Finish owned-resource cleanup and the requested handoff. Keep the whole goal open if required work remains.

An explicit stop suppresses continuation until authorized resume. A question, model failure or intermediate report must not silently erase pending work. Keep implementation, test evidence and state changes attributable to the current task.
