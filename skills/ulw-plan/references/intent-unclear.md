# Missing intent or constraints

Inspect the existing product, user-provided examples and current records. Distinguish missing information from a routine implementation choice. Ask only the question that changes the intended outcome or an irreversible action; use reasonable defaults for reversible details.

Preserve explicit requirements while investigating. Record assumptions in the plan and continue independent preparation. Do not make an unanswered question an implicit approval. Do not replace the user’s product with an easier demonstration.

Once the outcome is clear, specify observable acceptance checks and follow the clear-intent workflow. Keep unresolved facts visible until evidence or the user resolves them.
