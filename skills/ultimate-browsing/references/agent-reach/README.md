# Source-specific research

Choose a source according to the requested evidence: career.md for opportunities, dev.md for software, search.md for discovery, social.md for posts, video.md for audiovisual material, and web.md for general pages.

An external tool named Agent Reach is optional. Inspect installed tools and their documentation before invoking it; this guide does not bundle or install that project. Preserve source URLs and failures regardless of the chosen provider.

Separate discovery from verification. Open the primary record, resolve its identity and freshness, and report coverage limits. Do not substitute tool availability or a search hit for completion of the research request.
