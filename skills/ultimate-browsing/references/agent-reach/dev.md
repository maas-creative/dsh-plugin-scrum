# Software sources

Use the official repository, pinned commit, licence and primary API documentation. Record whether a feature is released, experimental or merely discussed in an issue. Compare the supported runtime with the project's actual environment.

Inspect installation scripts before executing them and keep validation isolated. For reusable code, retain applicable notices and preferred source. A public repository is not automatically freely relicensable.

Report reproducible tests and exact versions. Do not infer compatibility from a README badge or merge unrelated forks without verifying their licences and interfaces.
