# Retrieval failure sequence

Inspect the first failure: transport error, missing document, authentication, challenge, invalid body or selector mismatch. Preserve the trace and target identity. The independent reader tries permitted public surrogates before its optional rendering ladder; authentication-required results stop that sequence.

Registry entries may be disabled, stale, gated by an environment flag, or proxy-only. Do not enable an anonymous relay implicitly. Browser-provider placeholders do not count as performed browser attempts. A real provider consumes the configured browser budget even if it fails.

After exhaustion, report the target and actual failed routes. Return partial evidence with its provenance rather than describing a challenge page as the requested article. Do not loop indefinitely or erase the original error with a generic success message.
