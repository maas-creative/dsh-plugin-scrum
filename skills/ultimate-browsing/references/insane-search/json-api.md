# JSON records

Locate a documented endpoint or an observed public request that actually backs the requested data. Record method, parameters, pagination and schema. Use only permitted credentials and never include tokens in report URLs or logs.

Check the response status, content type and parsed schema. Distinguish an empty result from an API error, rate limit or HTML login page. Follow the documented continuation token until the requested scope is complete; report any unvisited pages.

Preserve identifiers, original timestamps and units before normalization. Cite the endpoint or the corresponding public record, and retain a reproducible query without secrets. Do not infer missing keys as zero or invent an undocumented write operation.
