# Transport profiles

The public reader's compatible MIT transport supports configured curl_cffi impersonation profiles. These alter transport characteristics; they do not grant account access or prove that a response is genuine content.

Use the configured profile list and record which attempt succeeded. Preserve certificate verification and validate each redirect destination. Do not disable security checks to obtain a green result.

For an authentication challenge, use the authorized browser or connector. For transport failure, report the actual provider error and remaining routes. Do not label profile rotation as a successful document read until body validation passes.
