# Optional page rendering

Use rendering only when a public page requires script execution and the host permits that backend. --no-playwright disables the reader's backend ladder. This does not disable an independently authorized host browser tool.

Verify provider availability before launching. Preserve the actual target and inspect the rendered body for interstitials or redirect stubs. Apply the requested selector only after confirming the page identity. A successful browser launch alone is not successful retrieval.

Limit attempts and timeouts. Close the resources created for this operation, retaining the user's unrelated tabs. If the provider is absent, report that absence; a placeholder is not a completed attempt.
