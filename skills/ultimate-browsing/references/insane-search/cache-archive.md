# Historical pages

Use the configured archive discovery service to locate a capture of the exact target URL. Validate the returned embedded target, query string, scheme and host; a similarly named page is not the same source. Retain snapshot_timestamp separately from an article's publication date.

The reader marks an accepted capture provenance=snapshot and trust=archive. If a capture time is absent, leave it null and explain that limitation. Registry verification dates describe the registry entry, not the age of the returned document. Missing or old verification dates remain visible in the trace.

A public 404 may have a useful historical capture. An authentication wall is not a reason to search for account data through archives. Compare historical evidence with a live official source before asserting a current deadline or policy.
