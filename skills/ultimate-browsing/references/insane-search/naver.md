# Reading a platform article

Confirm the canonical article or post URL before extraction. Inspect the current page for an embedded document, viewer frame or public JSON source; follow only a source that retains the requested item's identity. Preserve Korean text and original timestamps before translation.

Use the public reader for accessible text. If the article is exposed only through interaction, inspect it in the authorized connected browser. Distinguish a publisher's article from search results, syndicated previews or a login wall.

Return the canonical link and extracted evidence with provenance. Do not assume a historical host or iframe path remains valid, and do not export cookies to make an inaccessible page appear public.
