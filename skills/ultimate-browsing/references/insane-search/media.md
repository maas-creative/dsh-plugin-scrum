# Non-text evidence

Identify the media type before choosing extraction. PDFs need text extraction and, when layout matters, rendered-page inspection. Images need visual inspection; scanned text needs OCR with uncertain characters checked against the image. Audio and video need a transcript or direct review of the relevant segment.

Retain page or time references and the original source URL. Describe missing subtitles, unreadable pages or incomplete extraction. A textual preview cannot establish a figure's value or the contents of an attachment that was not downloaded.

Keep downloads inside the task's allowed directory and validate the resulting file. Do not run downloaded executables or embedded scripts as a reading step.
