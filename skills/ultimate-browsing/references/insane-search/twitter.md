# Social-post evidence

Identify the account and post ID. Prefer the available authorized connector or host browser. The separate x-search tool requires its configured credentials and model policy; loading this guide does not create them.

Keep the original post URL, timestamp and visible text. Distinguish the author from quoted or reposted material. If media carries the claim, inspect the media rather than relying on preview text.

Third-party mirrors and cached copies are alternate evidence, not proof of current visibility. Note unavailable or deleted content. Never infer a full conversation from one search snippet.
