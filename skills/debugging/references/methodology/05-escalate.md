# Escalate the measurement rather than abandon the task

When the current observation cannot distinguish explanations, identify the missing evidence precisely. Alternatives include a local reproduction, protocol capture, debugger breakpoint, structured trace, persisted receipt, browser network inspection or comparison with a pinned working build. Choose the least invasive method that answers the question.

A tool failure should be recorded with the attempted command and error. Check another available measurement before reporting an external blocker. Request user input only for information or access that cannot be recovered independently, and explain its direct connection to completion. Never request that credentials be pasted into chat.

Escalation does not authorize new workers, other models, global installations or production access. Preserve those constraints. State which question has been answered and which remains open; do not confuse a diagnostic limitation with the underlying cause.
