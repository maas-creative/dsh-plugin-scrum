# Verify the repaired behavior end to end

Run the regression, related caller tests and required standard checks on the final code. Use the actual runtime when a mock cannot establish compatibility. For UI failures inspect the visible result, input, state transitions and errors at desktop and relevant narrow widths. For persistence compare original records and restart behavior.

Verify both the failed scenario and representative valid behavior. For an agent workflow inspect planning, authorized delegation, collected results, artifact checks, progress writes and owned shutdown. A child saying complete is not artifact verification. An integration test must establish the expected persisted receipt and reject unverified completion.

Record commands, versions, build identity, exit codes and evidence locations. Separate mocks, fixtures and actual external connections. Do not substitute a faster test schedule for production settings and claim equivalent evidence. Report incomplete gates as incomplete, while continuing work within the authorized scope.
